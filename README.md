# A Little Box of Memories — For Roksi

A responsive, offline-friendly trilingual (English/Arabic/Polish) memory-box website for Roksi. Includes apology letters, shared memories, a live elapsed-time counter, timeline, personal-interest cards, random memory picker, future wishes, and a 100-day milestone. The mini quiz and voice-letter features are intentionally not included.

## Run locally

Open `index.html` in any modern browser. No build step, server, external font, image, or JavaScript library is required.

## Publish with GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`, then save.
4. GitHub will show the published URL in the Pages section.

## Included sections

- Live counter from August 9, 2026 (elapsed days plus current day number).
- Shared timeline with dated moments from the chat.
- Roksi’s interests and remembered details.
- Random memory picker, future wishes, and 100th-day countdown.
- Language switch updates all section labels and content in English, Arabic, and Polish.

The 100th inclusive day is **November 16, 2026**.

## Personalization

All page text and letters are in the `content` object near the bottom of `index.html`. English, Arabic, and Polish versions can be edited independently.

The page uses no analytics, tracking, external services, or automatic audio.
